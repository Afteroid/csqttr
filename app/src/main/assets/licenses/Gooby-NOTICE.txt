This repository is an independent Rust implementation of a SOCKS5 traffic
strategy engine. It does not contain copied source code from NoDPI.

CSQTTR modifications: embedded runtime lifecycle, bounded connection setup,
and an optional experimental TURN/TCP Allocate-header splitting preset.
The original base and ZIP/Lua rule interfaces are retained.
